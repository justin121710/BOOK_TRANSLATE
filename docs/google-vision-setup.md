# 取得 Google Cloud Vision API 金鑰

這支 App 用 Cloud Vision 做 OCR 與版面座標偵測。整個設定大約五分鐘。

---

## 步驟一：確認有專案，且已啟用計費

到 [Google Cloud Console](https://console.cloud.google.com/)，左上角的專案下拉選單
確認有一個專案（沒有就按「新增專案」，名稱隨便取，例如 `book-translate`）。

**Vision API 一定要專案有連結計費帳戶才能用**，即使你只會用到免費額度。
你已經申辦試用版的話，計費帳戶就存在了（附帶 US$300 額度），
到 [計費頁面](https://console.cloud.google.com/billing) 確認專案有連到它即可。

> 試用期間不會自動轉正式收費。額度用完或到期時服務會停掉，
> 而不是開始扣你的信用卡，除非你手動升級成付費帳戶。

---

## 步驟二：啟用 Cloud Vision API

直接開這個連結，確認上方的專案選對了，按「啟用」：

<https://console.cloud.google.com/apis/library/vision.googleapis.com>

（手動路徑：左側選單 → API 和服務 → 程式庫 → 搜尋 `Cloud Vision API` → 啟用）

---

## 步驟三：建立 API 金鑰

到 [憑證頁面](https://console.cloud.google.com/apis/credentials)：

1. 上方「**+ 建立憑證**」→ 選「**API 金鑰**」
2. 跳出一組 `AIza...` 開頭的字串，先複製起來
3. **先別關掉**，按「編輯 API 金鑰」進入下一步做限制

---

## 步驟四：鎖住這把金鑰（重要）

這把金鑰會出現在瀏覽器發出的請求網址裡，任何能看到你螢幕或開發者工具的人都拿得到。
不設限制的話被撿走就會被拿去燒你的額度。

### 應用程式限制

選「**網站**」（Websites / HTTP 轉介網址），加入這些項目：

```
http://localhost:5173/*
```

之後部署到 GitHub Pages 再加上：

```
https://<你的GitHub帳號>.github.io/*
```

### API 限制

選「**限制金鑰**」，在清單裡只勾 **Cloud Vision API**。

按「儲存」。設定生效可能要等一兩分鐘。

> 網站限制擋得住隨手撿到金鑰就拿去用的人，但擋不住刻意偽造 Referer 標頭的人。
> 它降低風險而不是消除風險。金鑰若外流過，就到憑證頁面刪掉重建一把。

---

## 步驟五：填進 App

打開 App 的**設定**頁，貼進「Google Cloud Vision API 金鑰」欄位，
按「**測試金鑰**」。顯示「可用 ✓」就成功了。

測試會實際打一次 API（1 個單位，約 US$0.0015）。

---

## 費用

| 項目 | 價格 |
|---|---|
| 每月前 1,000 單位 | **免費** |
| 之後每 1,000 單位 | 約 US$1.50 |

一頁書 = 1 個單位。所以每個月前 1000 頁不用錢，
之後大約**一本 300 頁的書 US$0.45**。

匯入的 PDF 若本身帶原生文字層，App 會直接取用文字座標、
完全跳過 Vision，那種情況下這部分零成本。

---

## 常見錯誤訊息

App 的設定頁會把錯誤翻成中文，對照如下：

| App 顯示 | 原因 | 怎麼修 |
|---|---|---|
| 金鑰格式不正確或已失效 | 貼錯或金鑰被刪 | 回憑證頁面重新複製 |
| 金鑰的 HTTP referrer 限制擋掉了這個網域 | 步驟四的網站清單沒包含目前網址 | 把目前網址加進去，注意結尾的 `/*` |
| 這個專案還沒啟用 Cloud Vision API | 漏了步驟二 | 回步驟二啟用 |
| 超過配額或速率限制 | 短時間送太多頁 | 等一下再試 |
| 金鑰沒有權限：billing… | 專案沒連計費帳戶 | 回步驟一 |
